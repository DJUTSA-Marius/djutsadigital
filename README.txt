DJUTSA DIGITAL — Portfolio
===========================

Fichiers :
- index.html                    → page principale
- style.css                     → tous les styles (thème clair/sombre automatique)
- script.js                     → toute la logique JS (console dev, palette de commandes,
                                   mode recruteur, upload d'images de projets, etc.)
- mentions-legales.html         → page « Mentions légales »
- politique-confidentialite.html→ page « Politique de confidentialité »

IMPORTANT — CV PDF
-------------------
Les boutons « Télécharger mon CV » / « CV PDF » pointent vers un fichier nommé :

    djutsa-digital-cv.pdf

Il te suffit de placer TON fichier CV, renommé exactement "djutsa-digital-cv.pdf",
dans le même dossier que index.html pour que les boutons de téléchargement
fonctionnent immédiatement (aucune autre modification nécessaire).

IMAGES DES ÉTUDES DE CAS
-------------------------
Dans la section « Projets » du site, survole une image de projet (Gestion de
Restaurant, E-Commerce Mobile, Dashboard Analytics) : deux boutons apparaissent
en bas à droite de l'image → « Ajouter une image » (upload) et l'icône poubelle
(suppression). Les images choisies sont enregistrées directement dans le
navigateur (localStorage), donc elles restent après un rechargement de page,
mais uniquement sur l'appareil/navigateur où tu les as ajoutées. Si tu changes
d'ordinateur ou de navigateur, il faudra les ré-ajouter, ou héberger les
images en dur (dans le HTML) une fois que tu as les visuels définitifs.

THÈME CLAIR / SOMBRE
---------------------
Le site suit automatiquement le thème choisi dans les réglages du système
d'exploitation ou du navigateur du visiteur (prefers-color-scheme). Aucune
action n'est nécessaire de ta part : bascule le thème de ton système pour
voir le résultat.
